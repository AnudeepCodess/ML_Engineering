# Lemmatization vs. Stemming (Quick Revision)

### Use Lemmatization When:
- Accuracy and context matter  
- Working on complex NLP tasks (chatbots, sentiment analysis, translation)  
- You can afford higher computational cost  

### Use Stemming When:
- Speed and efficiency matter more than precision  
- Doing simple text normalization (search, IR, keyword matching)  
- Resources are limited  

**Rule of thumb:**  
Lemmatization = correctness & meaning  
Stemming = speed & simplicity
